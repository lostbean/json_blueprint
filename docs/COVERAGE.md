# JSON Blueprint design coverage

- The package has two contexts: [contracts](design/contracts/design.typ) and [generation](design/generation/design.typ), related as declared in the [context map](CONTEXT-MAP.md). The root [design](design/design.typ) owns cross-context foundation, system structure and repository verification.
- `captured` names an owning section. Parts the design does not yet cover appear in a pending ledger rather than as a captured row.
